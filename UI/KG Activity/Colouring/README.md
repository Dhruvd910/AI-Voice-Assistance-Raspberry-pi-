# Colouring pages

Line drawings for the KG Workbook's colouring page (`kg_workbook.py`, `PICTURES`).
All of them come from Openclipart, which releases everything it hosts into the
public domain. Each was downloaded as the 800px PNG
(`https://openclipart.org/image/800px/<id>`) on 2026-10-13.

What makes a picture work here: bold black outlines that CLOSE (a tap fills the
area under the finger, so a gap lets the colour leak out), and no dotted or
hatched shading -- stippling turns into black blobs. Drawings tried and dropped
for that reason: the elephant (214373), flower (214395), tree (213774), car
(215974) and fish (214577).
