# Custom pictures

Drop an image here and name it in `kg_content.py` where an emoji would go:

    ("Y", "Yak", "yak.png"),

Why this exists: some words a child is actually taught have no emoji at all, and
the nearest one is the wrong animal or the wrong object. On a chart a child is
learning from, that is worse than no picture.
